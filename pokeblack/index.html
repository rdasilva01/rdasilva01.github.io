Pokémon Black · matching decompilation

pokeblack

Pokémon Black's source code, written again in C one function at a time, until it compiles back into the very same game, byte for byte. Once all of it is C, it becomes a port that runs natively on Windows and Android, the way pokefirered-x does for FireRed.

How it's done

Byte for byte

A function counts when the original compiler, Metrowerks CodeWarrior for the DS, turns its C into exactly the bytes the game has. After every change the whole game is rebuilt from the C and checked against the cartridge's copy.

Black 2 as a starting point

Black 2 shares much of Black's code. Where the pokebw2 decompilation has a function Black also has, its C is taken over and changed into Black's own version: other numbers, smaller structures, features Black 2 added taken out.

Files, not just functions

The game was written as source files, and each one is rebuilt whole: its functions, its data, its place in the game. A file is complete when the game links it from the C instead of the original bytes.

Then the port

With the game in C, it can be compiled for a PC or a phone instead of the DS, with the DS's screens, sound and buttons done by the port, as for FireRed and HeartGold.

By kind of code

The game's own code is written in C by Game Freak; the rest is Nintendo's libraries and other companies' middleware, linked into the game.

Every part of the game

The DS keeps one program in memory and swaps in overlays, pieces of code loaded for a screen or a feature: the battle, the bag, the Global Trade Station. Each square is one of them, as large as its code, coloured by how much of it is matching C. Pick one to see its numbers.
